Armin is a spaced-repetition flashcard app for web and mobile. You write cards, and Armin schedules them with FSRS so you review each one shortly before you'd forget it.

Cards also form a **prerequisite graph**. A card stays locked until you've learned what it builds on, so you study foundations first.
