Armin's hosted MCP server lets your assistant create cards, link prerequisites, and manage your library. The assistant writes the cards; Armin stores them and schedules your reviews.

You need an [Armin account](https://armincards.app/sign-up) with a verified email and an assistant that supports remote MCP servers with OAuth. Your provider's plan and workspace restrictions apply.

## Server details

**MCP server URL:**

`https://intent-bullfrog-922.convex.site/mcp`

- **Transport:** Streamable HTTP.
- **Authentication:** OAuth authorization code flow with S256 PKCE and dynamic client registration. Choose OAuth; no API key or client secret is needed.
- **Scopes:** `armin:read`, `armin:write`, `armin:import`, and `armin:study`. A client that asks for no scope receives all four. A connection sees only the tools in the groups you approve.

The URL is an endpoint, not a webpage. Opening it in a browser doesn't test the connection.

**AI setup** in Armin's sidebar shows these steps with copy buttons, plus a prompt that lets Claude Code or Codex set up the connection itself.

## Connect Claude

1. In Claude, open **Customize → Connectors → Add custom connector**.
2. Name it **Armin** and paste the MCP server URL.
3. Choose **Connect**, then sign in to Armin and approve the access.
4. Enable Armin in your conversation.

In a managed workspace, an owner may need to allow the connector first. See [Claude's custom connector guide](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp).

## Connect ChatGPT

1. Open [ChatGPT Plugins](https://chatgpt.com/plugins).
2. Choose **+ → Add custom MCP server**, name it **Armin**, and enter the MCP server URL.
3. Choose **OAuth**, review the warning, and select **Create as a plugin**.
4. Sign in to Armin and approve the connection.
5. In a conversation, type **@**, select Armin, and send your request.

If the client asks for a client ID or secret, use automatic registration. Armin has no shared secret. See [OpenAI's connection guide](https://developers.openai.com/plugins/deploy/connect-chatgpt).

## Connect Gemini

Gemini calls MCP servers "custom apps". You need a personal Google Account (not work or school), to be 18 or older in the US, Gemini in English, and Keep Activity on.

1. On a computer, open [gemini.google.com](https://gemini.google.com).
2. Open **Settings → Connected Apps** (if it's missing, choose **Personal Intelligence** first).
3. Under **Custom apps**, choose **Add a custom app**.
4. Paste the MCP server URL and choose **Next**. Skip **Advanced features**.
5. Sign in to Armin and approve the connection.

Apps added on the web also work in the Gemini mobile app. See [Google's guide](https://support.google.com/gemini/answer/17209137).

## Connect coding agents

Claude Code:

```sh
claude mcp add --transport http armin https://intent-bullfrog-922.convex.site/mcp
```

Run `/mcp`, select **armin**, and authenticate. Add `--scope user` to use it across projects.

Codex:

```sh
codex mcp add armin --url https://intent-bullfrog-922.convex.site/mcp
codex mcp login armin
```

Approve the connection in the page that opens. Use a current client version with remote MCP and OAuth support.

## Permissions

Each new connection asks for your approval and lists what it requests. The four groups cover your whole library, including decks you add later. There are no per-deck choices.

- **Read** (`armin:read`): read decks, cards, prerequisite links, study stats, and the authoring and Anki guides.
- **Write** (`armin:write`): create, edit, archive, and move cards; create and rename decks; change prerequisite links.
- **Import** (`armin:import`): convert and stage Anki files, upload their images, and publish the decks after you approve the preview.
- **Study** (`armin:study`): show due cards and record your own ratings.

An assistant can't permanently delete cards or decks, reschedule cards, upload images outside an approved Anki import, export your library, or manage your account. Ratings are recorded only when you give them, one card at a time.

Client names aren't verified. Check the client name and callback origin on the consent screen.

## Manage or disconnect

Open [Settings](https://armincards.app/settings) → **AI assistants** to see connections and their access, read recent activity, or disconnect. Disconnecting stops access immediately and keeps your decks and cards. Removing the connector in the assistant alone doesn't guarantee access has ended. Reconnecting needs a new approval.

## Try these requests

- “Make an Armin deck from these lecture notes, with prerequisites.”
- “Find the card about photosynthesis and fix its answer.”
- “Show me this deck's cards and how they depend on each other.”
- “How is my retention, and which decks are weakest?”

## Available tools

### Read (`armin:read`)

| Tool                 | What it does                                                                                             |
| -------------------- | -------------------------------------------------------------------------------------------------------- |
| `list_decks`         | Lists decks, 200 per page, with card counts and cards due now.                                           |
| `search_cards`       | Finds cards by text, deck, or tag.                                                                       |
| `read_deck`          | Reads a deck's cards in pages, plus its prerequisite links.                                              |
| `get_study_overview` | Summarizes due cards, new cards, streak, 30-day retention, and the five weakest decks.                   |
| `get_card_details`   | Shows one card's content and each review unit's state, stability, difficulty, reps, lapses, and history. |
| `get_guide`          | Returns the card-writing guidance or the Anki converter kit and import workflow.                         |
| `anki_import_status` | Reads a staged import's progress, counts, unresolved notes, and deck links.                              |

### Write (`armin:write`)

| Tool                | What it does                                                                                  |
| ------------------- | --------------------------------------------------------------------------------------------- |
| `save_cards`        | Saves 1–50 text cards and up to 100 prerequisite links atomically, in a new or existing deck. |
| `update_card`       | Edits one card, checking its version and keeping existing review items.                       |
| `set_card_archived` | Archives or unarchives a card, keeping its review history.                                    |
| `update_deck`       | Changes a deck's name or description.                                                         |
| `set_prerequisite`  | Adds or removes a same-deck prerequisite link, rejecting cycles.                              |
| `move_card`         | Moves a card between decks, keeping study state; refuses to discard prerequisite links.       |

### Import (`armin:import`)

| Tool                       | What it does                                                               |
| -------------------------- | -------------------------------------------------------------------------- |
| `anki_import_start`        | Starts a staged import and returns a scoped image upload token.            |
| `anki_import_add_batch`    | Stages up to 100 cards and 1,500 review items, with explicit skip reasons. |
| `anki_import_upload_token` | Issues a fresh upload token.                                               |
| `anki_import_finalize`     | Publishes an approved import after checking its preview checksum.          |
| `anki_import_cancel`       | Cancels an import and removes its staged data.                             |

### Study (`armin:study`)

| Tool            | What it does                                                                                                  |
| --------------- | ------------------------------------------------------------------------------------------------------------- |
| `get_due_cards` | Returns the next due review units in queue order, with prompts and a state token. Answers come separately.    |
| `rate_card`     | Records your rating for one review unit. The assistant must never choose it; stale state tokens are rejected. |

Supported card types are basic, reversed, cloze, and typed-answer. Before writing cards, the assistant should call `get_guide` with topic `authoring`. Edits that remove review items or change image content must be made in Armin.

Each connection can make 60 writes per hour on Free (600 on Pro) and 2,000 reads per hour on Free (6,000 on Pro). Ratings count as writes. An account can have 20 active connections, and normal library quotas apply. Large card sets need several batches; each batch succeeds or fails as a unit. Stale edits are rejected rather than overwriting newer changes.

## Troubleshooting

**The assistant can't see a deck.** Confirm you signed in to the right account and the connection is listed under **Settings → AI assistants**. With only the read group, editing tools stay hidden.

**No Armin tools, or missing permissions.** The connection may lack the needed permission groups. Reconnect and approve the groups you want.

**Sign-in or approval expired.** Start again from your assistant; consent requests expire after ten minutes. If a working connection reports an authentication error, reconnect.

**A write is refused.** For a version conflict, have the assistant re-read the card or graph and retry. For a quota error, wait for the hourly reset or use smaller batches. Input errors name the field and rule; have the assistant correct that argument.

**The custom connector option is missing.** Ask your provider's administrator about your plan and workspace policy.

**The server can't be reached.** Use the exact HTTPS URL, including `/mcp`. Hosted chat apps can't reach a local development server. If failures persist, [open an issue](https://github.com/andy-spike/armin/issues) with the client name, time, and error. Leave out passwords, codes, tokens, and private card content.

## Data and privacy

Armin stores authorized card content, deck information, prerequisite links, and connection records. It doesn't fetch the source pages you share or run an AI model for you; your assistant provider handles the conversation under its own policies. Activity summaries are kept for 90 days with no card snapshots or source documents. Disconnecting doesn't delete content the assistant saved. See the [Privacy Policy](https://armincards.app/privacy) and [Terms](https://armincards.app/terms).

## Public test account

To evaluate Armin, sign in with `reviewer@armincards.app` and password `ArminDemo123!`. The account is shared and disposable: everyone can see and change its library, so add nothing private. It resets to a sample deck about every six hours. Sessions and OAuth connections survive a reset, but links to deleted cards and decks stop working.

## Anki imports

Call `get_guide` with topic `anki_import` for the converter kit and import protocol. The assistant needs file access and Node.js. It converts the file in its own workspace, keeps supported images, and repairs or skips unsupported cards. Review the final preview from `anki_import_status` with `includePreview: true` and approve it before the decks publish. Assistant imports start fresh; browser import can keep study progress.
