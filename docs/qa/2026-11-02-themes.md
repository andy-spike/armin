# Color themes

Date: 2026-11-02
Checkout: `t3/3f5c97bb` worktree
Environment: this checkout's local web app at
`http://armin-c2ae4bf056.localhost:14412` (`pnpm dev`), headless Chromium
through agent-browser at 1280×900, with the system color scheme reporting
dark. A second agent-browser session with empty storage stood in for a
second device; it is not a real second device.

## Change

- Settings → Appearance → Theme has a Mode switch (System, Light, Dark) and
  separate Light theme and Dark theme pickers. The sidebar toggle flips the
  mode; right-click picks System, Light, or Dark.
- Built-in themes: Flexoki Light and Dark (default, unchanged), plus VS Code's
  built-in themes: Light Modern, Dark Modern, Light+, Dark+, Light and Dark
  High Contrast, Quiet Light, Solarized Light and Dark, Monokai, Monokai
  Dimmed, Abyss, Kimbie Dark, Tomorrow Night Blue, and Red. "Dark/Light
  (Visual Studio)" are left out: in Armin they would be identical to Dark+
  and Light+.
- Custom themes take seven seed colors (background, text, accent, and the four
  rating colors). `@armin/core/themes` derives every other token and keeps
  accent, rating, and status colors at WCAG AA against the background. The
  editor shows a live preview and warns when text contrast is below 4.5:1.
- The choice and custom themes are stored per account in the Convex
  `appearance` table, and applied on every page, including the landing,
  pricing, and sign-in pages. The browser keeps a cached copy that
  `public/theme-init.js` applies before first paint.
- The review rating buttons' per-theme shades moved from hardcoded hex classes
  into `--armin-rate-*` tokens. Flexoki's values are unchanged.

## Steps

1. Signed in as the sample account. Appearance showed Mode System, Flexoki
   Light / Flexoki Dark; the page rendered `flexoki-dark` because the system
   reports dark (`01`).
2. Picked Monokai as the dark theme. `<html data-theme-id>` became
   `vscode-monokai`; Review rendered in Monokai, with readable labels on all
   four rating buttons (`02`).
3. New theme opened prefilled with the theme on screen (Monokai). Changed the
   name and background, text, and accent seeds. The preview turned into a
   light theme and deepened the rating colors for contrast (`03`). A pale text
   color showed "Text contrast is 1.5:1" (`04`); restored it.
4. Saved. The theme became the light slot's theme; switching Mode to Light
   applied it across the app and listed it under "Your themes" (`05`). The
   device cache held the new appearance.
5. Second session with empty storage: the sign-in page showed Flexoki Dark;
   after sign-in the custom theme loaded from the account. `/pricing` used it
   too (`06`).
6. In session 1, the sidebar toggle switched to dark mode; session 2 changed
   to Monokai without reloading.
7. Deleted the custom theme (`07`). The light slot fell back to Flexoki Light.
   After a reload the page still showed Monokai, and no console errors appeared.
8. With Flexoki Light, `--armin-rate-good` resolved to `#637b0a` and
   `--armin-rate-again` to `#af3029`, the same as the previous hardcoded
   values. No inline `--armin-*` properties were left on `<html>`.

A script checked every VS Code theme's derived tokens: text, muted, faint,
accent, the rating buttons and their hovers, and the four status badges all
clear 4.5:1.

## Polish pass

Same environment, desktop 1280×900 and an emulated 390×844 phone viewport
(not a real device).

- Theme pickers: each option shows a small chip of the theme (its text on its
  background, an accent square, and the four rating colors along the bottom).
  The popup grows to fit the longest name, so no name is cut off, and the
  trigger shows the selected theme's chip. Custom themes sit under a ruled
  "Your themes" group (`08`, `09`).
- "New theme" moved from the section sidebar into a "Your themes" row that
  explains where a new theme starts. New themes are named after the theme
  they copy ("Flexoki Light copy").
- Editor: the name field spans the dialog; colors are grouped as Page and
  Rating buttons; each color is one field with the swatch joined to its hex
  value, and an invalid hex value turns the field's border red. The preview has
  a heading and shows whether the theme is light or dark, plus interval labels
  on the rating buttons. The contrast warning has an icon, so it doesn't rely on
  color alone. Enter in any field saves (`10`, `12`).
- Sidebar theme menu: modes are radio items under a "Mode" label, plus a
  "Theme settings" item that opens Settings → Appearance (`11`).
- Detector: the remaining advisories are the chip's "Aa" and the preview's
  interval labels, kept below the type scale on purpose because they are drawn
  at miniature size.
