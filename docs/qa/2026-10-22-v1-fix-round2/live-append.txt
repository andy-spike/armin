Why the dependent was not appended in one earlier verification run:
the page polled `armin.review.queue` through TanStack Query. That call uses
`ConvexReactClient.query`, which returns the client's local cached result when
one exists and unsubscribes once its promise resolves. A refetch shortly after
the rating could therefore read the pre-rating local snapshot (the sidebar's
live `convexQuery` badge already showed the new count, while the session stayed
at "2 / 10"). Reloading created a fresh client and showed the admitted unit.
The fix subscribes through `convexQuery(api.review.queue, ...)` on both review
routes, so every server queue result updates the session; `useNow` still
advances the query args so due times re-evaluate without a write.
